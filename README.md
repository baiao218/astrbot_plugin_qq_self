# 自我形象 · astrbot_plugin_qq_self

让她自己换 QQ 头像、改个性签名。

## 能做到什么，做不到什么

| 需求 | 可行性 | 依据 |
|---|---|---|
| 换 QQ 头像 | ✅ 可以 | NapCat 扩展接口 `set_qq_avatar` |
| 改个性签名 | ✅ 可以 | NapCat 扩展接口 `set_self_longnick` |
| 改昵称 | ⚠️ 能，但不建议 | `set_qq_profile` 里 `nickname` 是必填项，改签名会连带改昵称 |
| 管理 QQ 零钱 | ❌ 做不到 | 见下 |

### 为什么零钱做不到

NapCat 是聊天客户端的钩子，不是支付客户端。整个包里没有钱包、余额、转账、红包
相关的任何接口——不是没实现，是协议层根本没有这个东西。

QQ 零钱背后是财付通，动钱要过支付密码或人脸校验，那是另一套独立体系，
和聊天协议不通。任何声称能「自动管理 QQ 零钱」的方案，要么是假的，
要么是在拿你的支付凭证去冒险。

要做账目管理，只能另做一本自己的账：记流水、算预算、提醒超支。
那管的是数字，不是钱。

## 依赖的接口

```python
# 换头像
await event.bot.call_action("set_qq_avatar", file="C:/path/to/x.png")
# file 支持：本地路径 / http(s) URL / base64://

# 改签名
await event.bot.call_action("set_self_longnick", longNick="今天风很大")
```

只有 NapCat / Lagrange 这类 OneBot 实现提供这两个动作。换到别的实现会报
「当前平台不支持 OneBot 动作」。

## 为什么限流

QQ 对头像和签名的修改有频率风控。短时间反复改，轻则静默失败，重则弹验证、
临时限制登录。

默认：头像 6 小时一次、签名 1 小时一次、每天合计 4 次。想改快可以，但没好处。

## 为什么默认只认主号

改头像是账号级操作。如果对所有人开放，陌生人只要哄她两句，就能让她把签名改成
广告、把头像换成别人的图。

所以三个工具默认只在 `admins_id` 的会话里生效，其余会话一律回：

> 换头像和改签名是账号级操作，只在她本人的会话里生效。这里不行——
> 不要替任何人改自己的形象。

这一条和人格里 §7.5「越权与上报」是同一个逻辑：她对自己同样没有处置权，除非那是你。

## 她的三个工具

| 工具 | 参数 | 说明 |
|---|---|---|
| `set_avatar` | `image` | 头像目录里的名字或关键词，也可以是图片 URL |
| `set_signature` | `text` | 新签名，默认 40 字以内 |
| `list_avatar_options` | — | 看看有哪些图可选 |

命名的用处在这里：目录里放 `雨天.png`、`深夜.jpg`、`旧照片.png`，
她挑的时候就是「换成雨天那张」，而不是「换成 3 号文件」。

分辨率上，关键词匹配不到多张时会把候选列出来让她重说，而不是随便挑一张。

## 命令

| 命令 | 作用 |
|---|---|
| `/换头像` | 不带参数列可选图；`/换头像 雨天` 换指定那张 |
| `/签名 今天风很大` | 直接改签名 |
| `/我的形象` | 当前昵称、上次换头像/改签名的内容与时间、剩余次数 |

均为管理员命令。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `enable` | `true` | 总开关 |
| `owner_only` | `true` | **强烈建议保持开启** |
| `owner_umo` | 空 | 留空用 `admins_id` 判断 |
| `avatar_dir` | 空 | 留空用插件数据目录下的 `avatars/` |
| `avatar_cooldown_minutes` | `360` | 换头像冷却 |
| `signature_cooldown_minutes` | `60` | 改签名冷却 |
| `daily_max` | `4` | 每天合计次数，`0` 不限制 |
| `signature_max_chars` | `40` | 签名长度上限 |

## 准备头像

把图片放进：

```
data/plugin_data/astrbot_plugin_qq_self/avatars/
```

支持 jpg / jpeg / png / gif / webp / bmp。文件名就是她嘴里的「那张图的代号」。

建议 512×512 以上的正方形，否则 QQ 会自己裁，构图容易歪。

## 验证

重启后私聊发：

```
/我的形象
```

能看到昵称和头像目录张数就说明通了。再发 `/换头像 雨天` 试真实修改。

如果返回「当前平台不支持 OneBot 动作」，说明用的不是 NapCat 系实现。

## 已知限制

- 改头像可能触发 QQ 安全验证（异地登录、设备变更时更明显）。首次失败正常，隔一天再试
- `set_qq_avatar` 需要 NapCat 能读到那个文件路径。跨机器部署时要用 URL 或 base64
- 头像生效有延迟，客户端缓存可能要几分钟才刷新
- 不支持改昵称：`set_qq_profile` 虽然能改，但它要求 `nickname` 必填，
  等于每次改签名都得重写昵称，风险大于收益
